## Purpose
This custom agent is designed to help with development in the `MindConnectSE104` repository. It specializes in the current project’s frontend HTML/CSS/JavaScript files and the backend Node.js authentication service.

## When to use
- When working on the project’s UI pages: `index.html`, `school.html`, `student.html`, `student.js`, `style.css`
- When editing or extending the backend auth service under `backend/src`
- When the task should remain within this repository and use local source context

## Specialization
- Frontend markup and styling for the app’s existing pages
- JavaScript logic for student interactions and frontend behavior
- Backend routes, controllers, models, repositories, and services for auth functionality

## Instructions
- Prefer concrete changes to files in this workspace rather than generic advice.
- Base recommendations on the existing repository structure and current files.
- When asked to implement features, preserve project style and avoid adding unrelated frameworks or external dependencies unless explicitly requested.
- If a requested task is unclear, ask for clarification before editing.
- Keep answers concise, actionable, and focused on code changes.

## Example prompts
- "Add a login page and connect it to `backend/src/controllers/AuthController.js`"
- "Fix the student form behavior in `student.js`"
- "Create a protected route in the backend that uses `authenticate.js`"
- "Improve the layout of `index.html` and `style.css` for mobile"

## Notes
- The agent should avoid using external internet searches and should rely on local project context.
- Use file-based guidance and only modify repository files when explicitly instructed.
