# MindConnect

MindConnect is a student mental-health support prototype with a student workspace, school/admin portal, and a local Node.js backend.

## Run

Open `index.html` with a local server, or run:

```bat
start-mindconnect.cmd
```

## Structure

- `index.html`, `student.html`, `school.html`: main browser entry pages.
- `assets/`: shared CSS and images.
- `student/`: student frontend modules.
- `school/`: school/admin frontend scripts.
- `shared/`: shared frontend state/data helpers.
- `backend/`: Node.js API and local data store.
- `tools/`: helper scripts and local static server.
- `tests/`: Playwright tests.
